# "The Phantom" -- 3lb Combat Robot
- This project is the KiCAD schematic of our battle bot that enabled us to visualize our electrical connections.
- We used 16 AWG wires that enables upwards to 18A of current
- We also used XT30 connectors for the batteries -> voltage rating of 500V, current rating of 15A, and instantaneous current rating of 30A.
